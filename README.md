# Python Programs Collection

## About the Project
This project contains three beginner-friendly Python programs
developed as part of my programming practice.

## Programs Included

### 1. Factorial of a Number
Calculates the factorial of a given non-negative integer.

### 2. Fibonacci Series
Generates the Fibonacci sequence for a specified number of terms.

### 3. Structure-to-Dictionary Conversion
Demonstrates representing student information using a Python
dictionary, similar in purpose to grouping related fields
in a C structure.

## Technologies Used
- Python 3
- Google Colab(link for the notebook: https://colab.research.google.com/drive/1KtlqAsu_OYnlx6sa4nS23gBfbu-zIXlb?usp=sharing)
- Git and GitHub for version control and hosting

## Requirements
- Python 3
- No external libraries are required for the basic programs.

## How to Run
The programs are currently available as code cells in the
notebook.

1. Open the notebook in Jupyter or Google Colab.
2. Run the relevant program cell.
3. Check the output displayed below the cell.

## Learning Outcomes
- Practiced variables, loops, and functions.
- Understood factorial calculation.
- Learned to generate Fibonacci numbers.
- Practiced representing structured information using dictionaries.
